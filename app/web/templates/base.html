HOW IT WORKS

Camera → Facial ROI extraction → rPPG / respiratory signal → Signal-quality validation → Personal baseline → Sustained-change detection → Reassessment recommendation.

TriageTracker looks for meaningful physiological change relative to a patient's own baseline rather than diagnosing from a single measurement.
