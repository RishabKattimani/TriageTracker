# Fixtures

These are synthetic optical fixtures, not wearable-validated physiology.

Generated by `python scripts/generate_fixtures.py` (also invoked by `./run.sh` when missing):

- `controlled_change.mp4` + `.json` — skin-tone patch whose color oscillates at 72 BPM, then 110 BPM. Enters the same `VideoSource` → rPPG → change-engine path as the webcam. The UI must not assign `REASSESS`.
- `stable_seated.mp4` + `.json` — synthetic stable 72 BPM pulse for optional checks.
- `no_face.mp4` — dark frames; must abstain and never alert.

Sidecar JSON may declare `kind: synthetic_pulse` so the processor can extract real RGB from a documented skin patch when MediaPipe finds no photorealistic face. Heart rate is still estimated from those pixels, never hardcoded.
